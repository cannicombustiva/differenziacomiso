# Coverage is recorded explicitly; absence of Pickups is not evidence

A new `schedule_coverage` table records the date ranges for which the Schedule is known to be authoritative, each row naming the source that produced it (the 2026 seed, or a `schedule_imports` row). A date **inside** Coverage with no Pickups is a genuine day off; a date **outside** Coverage is unscheduled, and the app must say so ("calendario non ancora disponibile") rather than assert that nothing is collected. The nightly Notification does not fire for a Reference day outside Coverage, and the offline cache carries the Coverage range alongside the Schedule rows so an offline device does not lie either. The migration that creates the table inserts the 2026 row (`2026-01-01`–`2026-12-31`, source `seed`) in the same transaction — deferring that to a manual step would make the deploy an outage.

The reason this cannot be inferred: `collection_schedule` holds **no rows at all** for every Sunday and every 5th Thursday ([ADR 0002](./0002-giovedi-alternation-week5-gap.md)), because per [ADR 0001](./0001-schedule-stores-final-state.md) the Schedule stores final state and a day with nothing collected has nothing to store. So "zero rows for this date" already means *legitimately nothing collected*, and is byte-identical to *we have never loaded this year*. Before this change, `buildNotificationMessage([])` returned "Domani non si effettua la raccolta" either way — meaning that on 1 January 2027, with the Schedule seeded only through 2026, every subscribed device in Comiso would have received a confident and permanent instruction to put nothing out.

**Considered and rejected: a marker row for every empty day**, which would make absence finally mean unscheduled. It rewrites the meaning of existing data, requires backfilling 2026, changes `group-collections`, and roughly doubles the row count, all to encode something two dates express. **Also rejected: deriving Coverage from `max(date)`** — it cannot represent a gap in the middle of the Schedule, which is exactly what a partial mid-year Import produces.
